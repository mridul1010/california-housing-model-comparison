# California Housing Model Comparison

## Overview

This project compares multiple Machine Learning regression models using the California Housing dataset. The objective is to predict house prices and identify the best-performing model through feature scaling, training, evaluation, and comparison.

## Models Used

* Linear Regression
* Ridge Regression
* Decision Tree Regressor

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Jupyter Notebook

## Evaluation Metrics

The models are evaluated using:

* RMSE (Root Mean Squared Error)
* R² Score

## Files

* `AI_ML_Task2_Model_Comparison.ipynb` – Complete implementation
* `Task2_Report.pdf` – Project summary and results

## Conclusion

This project demonstrates feature scaling, model optimization, and performance comparison to identify the most suitable regression model for California housing price prediction.
